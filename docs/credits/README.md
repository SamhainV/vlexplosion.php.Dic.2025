# Evidencias musicales públicas para pruebas

Las respuestas de `tests/credits/reference/` y `scope-public-responses.json` son capturas musicales públicas de MusicBrainz. No son volcados de la aplicación, cachés de sesiones ni copias de una colección personal. Los ejemplos de usuarios/notas de tests son ficticios.

Los datos básicos de MusicBrainz se ofrecen bajo CC0 y los suplementarios bajo CC BY-NC-SA; consultar https://musicbrainz.org/doc/About/Data_License . Se mantienen las fuentes e identificadores originales de las respuestas. `reference/index.json` identifica las ediciones y `reference/SHA256SUMS` fija sus capturas. Las pruebas no requieren volver a descargarlas.

Los resultados generados en este directorio, así como todas las bases y capturas en tests/runtime, se excluyen de Git. No colocar aquí recibos de producción, auditorías privadas ni respaldos.
